Dust motes and embers for comp, rebuilt

MoteField adds floating dust and fire embers to a shot in Nuke from the lighting department's utility pass, with no 3D particle render. It shows up in the Nuke viewer as an ordinary image, with depth of field and motion blur, to plus or over onto the comp. This page tracks the rebuild.

This update ·

  • One node, nothing to install. MoteField is now a single node you paste or drag into a Nuke 15 script. No NUKE_PATH, nothing in .nuke, and it writes no files. It works in plain Nuke, not just NukeX.
  • The rendering lives inside it. BlinkScript kernels do everything on each frame: the motes' motion, the light and shadows, bounce light, holdouts, defocus and motion blur. They run on the GPU when there is one. Plain Nuke runs a kernel saved in a script, and your check node came up green.
  • It reads the pass by itself. On connecting, it finds the layers and reads the camera, lens and shutter from the EXR header on every frame. It works out whether positions and depth are premultiplied, then fits the dust box. Check shot reports what it found.
  • The same dust as before. The kernels are tested against the Python renderer from the last update: the same random numbers bit for bit, the same motes to half a millimetre, and the same picture.
  • Gone: the install, the frame cache, the render callback and the browser viewer. The node renders like any other node, and Nuke's viewer is the live view.

In Nuke 15

One node. Nothing to install, and nothing written to disk.

Download MoteField.nk The BlinkScript check

  1. Paste it in. Drag MoteField.nk into the Node Graph, or open it in a text editor, copy everything and paste. With the utility pass Read selected, it connects itself.
  2. Connect the utility pass to the utility input. The node finds the layers, reads the camera from the header on every frame, takes the frame range and fits the dust box. Optional: the plate, to judge the look, and a pass with surface colour, for bounce light.
  3. Check shot, aim, tune. Check shot says what it found. Set the light's heading and elevation, then tune with Amount, Brightness, Air and Steady.
  4. Comp it. Plus the node onto the comp, or set Alpha to matte and merge over. It renders like any node: Writes and the farm need nothing special.

The full guide, and what to report back, is docs/NUKE.md.
